# BookClub — система учета книг в книжном клубе

Веб-приложение для ведения общего каталога книг и отслеживания читательского прогресса участников клуба. Реализация: **FastAPI + SQLAlchemy + PostgreSQL + Docker Compose**.

## Возможности
- добавление, просмотр, редактирование и удаление книг (CRUD);
- хранение названия, автора, жанра, статуса, даты добавления, оценки и заметок;
- поиск по названию и автору, фильтрация по статусу;
- статистика: общее количество, прочитанные, читаемые, запланированные книги и средняя оценка;
- визуальная панель активности, журнал действий;
- REST API и интерактивная документация Swagger.

## Запуск
Требуются Docker и Docker Compose.
```bash
docker compose up --build -d
```
Открыть:
- интерфейс: http://localhost:8000
- Swagger: http://localhost:8000/docs

Остановка:
```bash
docker compose down
```
Для удаления данных вместе с томом БД:
```bash
docker compose down -v
```

## Локальный запуск (без Docker)
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
По умолчанию используется SQLite-файл `book_club.db`. Для PostgreSQL задайте `DATABASE_URL`.

## Тестирование
```bash
pytest -v
```
Тесты используют отдельную временную SQLite БД и не изменяют рабочие данные.

## Структура
- `app/main.py` — маршруты FastAPI;
- `app/models.py` — ORM-модель книги;
- `app/schemas.py` — проверка входных и выходных данных;
- `app/services.py` — бизнес-логика и пользовательские исключения;
- `app/database.py` — подключение к БД;
- `app/static/` — веб-интерфейс;
- `tests/` — автоматические тесты.

## Краткая справка
Статусы книги: «В планах», «Читаю», «Прочитана». Оценка необязательна и принимает целое значение от 1 до 5. Удаление требует подтверждения. Ошибки валидации API возвращаются с кодом HTTP 422, отсутствующая запись — 404.
